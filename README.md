# Локальный календарь дней рождений

Это обычное HTML-приложение. Выбранный `.xlsx` используется как база данных.

## Запуск на Windows

1. Установите [Node.js](https://nodejs.org/) версии 20 или новее.
2. Распакуйте архив в постоянную папку.
3. Запустите `start.bat`.
4. В открывшемся Chrome или Edge нажмите «Выбрать Excel» либо «Создать базу».

Дополнительные пакеты и `npm install` не нужны.

Для остановки нажмите `Ctrl+C` в окне сервера или закройте его.

## Запуск вручную

```bash
node server.js
```

## Excel как база

- Системный диалог позволяет выбрать путь к Excel-файлу.
- Разрешение и выбранный файл запоминаются браузером локально.
- Изменения записываются непосредственно в выбранный `.xlsx`.
- Исходные листы и их форматирование не перезаписываются.
- Структурированные данные приложения находятся на очень скрытом служебном листе `_BirthdayApp`.
- Кнопка «Сохранить копию» создаёт резервную копию в выбранном месте.

## Формат исходной таблицы

- В книге может быть несколько листов. Название каждого листа считается городом.
- Приложение сканирует ячейки с датами рождения.
- Начальный жирный фрагмент ячейки считается ФИО.
- Текст между ФИО и датой считается должностью. Скобки необязательны.
- После первого сохранения приложение использует служебный лист, поэтому дальнейшее чтение не зависит от оформления исходных ячеек.

## Цвета объектов

Цвет можно назначить в карточке сотрудника или через кнопку «Цвета объектов». Изменение применяется ко всем сотрудникам с таким же названием объекта и сохраняется в Excel.

Не открывайте `public/index.html` двойным щелчком: доступ к системному выбору и изменению Excel-файла требует `http://localhost`. Запускайте приложение через `start.bat`.

Рекомендуемые браузеры: актуальные Google Chrome или Microsoft Edge. Firefox не поддерживает прямую запись в выбранный файл; в нём доступно только сохранение копии.
