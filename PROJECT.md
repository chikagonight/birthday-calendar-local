# birthday-calendar-local

Локальное веб-приложение «Календарь дней рождений» для Windows. Excel-файл (`.xlsx`)
выступает единственной базой данных — отдельного бэкенда/БД нет.

## Репозиторий
- origin: `git@github.com:chikagonight/birthday-calendar-local.git`

## Стек
- Node.js >= 20, без внешних npm-зависимостей (`node_modules` отсутствует).
- `server.js` — минимальный HTTP-сервер (`node:http`) на `127.0.0.1:8090` (порт задаётся через `PORT`, см. `start.bat`), только
  раздаёт статику из `public/` и отвечает на `/api/health`. Никакой бизнес-логики
  и работы с файлами на сервере нет.
- Вся логика — на клиенте: `public/app.js` (vanilla JS, без фреймворков).
- Чтение/запись `.xlsx` в браузере — через `public/vendor/xlsx.full.min.js`
  (SheetJS) и `public/vendor/jszip.min.js`.
- Доступ к файлу базы — через File System Access API браузера
  (`showOpenFilePicker` / `showSaveFilePicker`), поэтому работает только в
  Chrome/Edge. Firefox не поддерживается (только экспорт копии).
- Хэндл выбранного файла запоминается в `indexedDB` (база `birthday-calendar`),
  чтобы не выбирать файл заново при каждом запуске.

## Запуск
- `start.bat` — двойной клик: проверяет Node.js, стартует `node server.js`,
  открывает `http://localhost:8090` в браузере (порт настраивается переменной `PORT` в `start.bat`).
  При отсутствии Node.js пытается установить его через winget (`OpenJS.NodeJS.LTS`), а при неудаче просит установить вручную.
- Вручную: `node server.js`.
- Проверка синтаксиса: `npm run check` (`node --check` для `server.js` и `app.js`).
- Открывать `public/index.html` напрямую (file://) нельзя — нужен http://localhost
  для работы File System Access API.

## Структура
- `server.js` — статик-сервер.
- `public/index.html` — разметка.
- `public/app.js` — вся логика приложения (~535 строк).
- `public/styles.css` — стили.
- `public/vendor/` — сторонние библиотеки (SheetJS, JSZip), подключены локально.
- `start.bat` — лаунчер для Windows.
- `README.md` — пользовательская инструкция (на русском).

## Формат данных в Excel
- Каждый лист книги = название города/объекта.
- Приложение парсит ячейки с датами рождения: жирный фрагмент в начале —
  ФИО, текст между ФИО и датой — должность.
- После первого сохранения данные дублируются на служебный скрытый лист
  `_BirthdayApp` (константа `APP_SHEET` в `app.js`) — дальнейшее чтение идёт
  оттуда и не зависит от исходного форматирования.
- Исходные листы и форматирование не перезаписываются.
- Цвет объекта применяется ко всем сотрудникам этого объекта и сохраняется
  в Excel.
- Кнопка «Сохранить копию» — резервная копия в произвольное место
  (через `showSaveFilePicker`).

## Особенности/ограничения
- Нет тестов, нет линтера, нет CI.
- Нет сборки — чистые статические файлы.
- Вся логика хранения завязана на File System Access API — переносимость
  ограничена поддерживающими браузерами (актуальные Chrome/Edge).
- Интерфейс и README — на русском языке.
